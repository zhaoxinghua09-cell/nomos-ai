### 🛡️ XCGS 治理系统（XCGS Governance System）

XCGS 是 Nomos AI 的治理底座，定位为**可审计、可认证、可举证**的 AI 治理体系：

- 以 **ISO/IEC 42001**（国标 GB/T 45081-2024 已等同采用）、**NIST AI RMF**（1.2 Agentic Profile）、**OWASP Agentic Top 10** 为底座；
- 落地六类可审计证据工件：决策日志、风险登记册、模型卡、变更记录、人类监督证明、事件台账；
- 与 **EU AI Act** 对自主 agent 的注册与治理要求对齐（具体强制时点以欧盟官方公报为准）；
- 回应行业「治理缺口本质是身份缺口」：以身份码 + 可审计证据链提供可举证的责任闭环。

> 中文语境请用全称「XCGS 治理系统」，与金融领域的 XCGS（金银交易所 MIC 代码）区分。
